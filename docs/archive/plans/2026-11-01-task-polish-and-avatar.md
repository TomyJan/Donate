# 任务页精修与登录头像修复计划

> 历史计划：记录当时的设计与验证，不代表当前功能、配置、发布状态或执行授权。现行入口见[文档索引](../../README.md)。

**目标：** 收尾任务页自动刷新、趋势/筛选/详情交互，校正捐赠按钮居中，并定位修复登录头像缺失。
**规格：** 用户 2026-11-01 的七项反馈；继续沿用 docs/task-queue-design.md 的队列安全约束，交互冲突以本次用户反馈为准。
**技术栈：** 现有 Go / SQLite / React / Motion，pnpm 与项目 Node 26；不新增依赖。
**已确认基线：** 66b16f3，此前 13 笔提交已全部补签，代码树未改变，v0.1.1 发布标签不动。

## 全局约束

- 不修改真实数据库、真实 .env，不写假执行历史，不把升级快照计入执行趋势。当前预览库仅有156条snapshot、无实际执行事件，全零应解释为空态。
- 保留鉴权/CSRF、user+CSRF作用域、慢请求不被轮询取消、离页/隐藏/撤权清理、稳定幂等键及租约栅栏。
- 不下载/持久化头像文件，不绕过签名、nonce、issuer、subject或头像URL安全检查；不在日志输出令牌、密钥或完整UserInfo。
- 复用原后台布局、订单式收纳筛选、确认浮层、分页和可访问控件；320/390/768/1280、深浅色和reduced motion均需核验。
- 实现者不可派子代理，不共享文件所有权，不自行占用完整build/E2E/18080，提交前与root协调Git索引。

## 审查重点

1. 移除刷新控件不能破坏慢网轮询或授权撤销，也不能让错误无法恢复。
2. 空趋势不是统计失败，不可计入旧快照或伪造执行数据；刷新已有曲线不应反复入场。
3. 窄屏单行工具栏不能挤掉搜索/重试/更多筛选，也不能把折叠控件留在tab顺序。
4. OIDC兼容不得降低token/nonce/issuer/subject验证或扩展头像URL到不安全源。
5. 整体居中不能让右侧下拉覆盖主操作或使支付状态确认动画无法完成。

## 执行取舍

1. UI 与 auth 按互不共享的文件并行；共享 i18n、Git 索引、构建和浏览器测试由主执行者串行协调。代价是集成必须统一验证，避免相互覆盖或误用旧构建。
2. 旧快照不伪装执行，五条事件序列全部为零才显示空态。代价是无法展示升级前并不存在的执行走势，保留真实零值与记录起点供核对。
3. 使用模块图已有的官方 x/net/idna 规范化主机后校验并存储相同 ASCII 主机。代价是增加直接依赖声明和严格拒绝不安全地址；没有依赖版本升级，合法国际化域名与 IPv6 已回归。
4. 取消选择放入既有更多筛选展开区，不增加窄屏主行控件，不由轮询擅自丢弃选择。代价是清选需要展开筛选，但不改变筛选、排序、分页或请求。
5. 头像继续使用远程 URL，不下载图片、不新增代理或 DNS 抓取，不根据缺少字段的旧日志推断线上唯一根因。代价是图片实际可达性、重定向或上游具体资料仍需部署后的诊断和浏览器网络证据确认。
